# Cricket Highlights Generator

## Project Overview

The **Cricket Highlights Generator** is a video processing system that automatically creates short highlight clips from a full-length cricket match.

Instead of watching long matches, users can quickly view important moments like **fours, sixes, and wickets** in a concise and engaging format.

## Problem Statement

Cricket matches are usually long, making it difficult for viewers to watch the entire game. Most viewers prefer short highlight videos, but identifying and extracting key moments manually is time-consuming.

## Objective

* Generate highlights from full match videos
* Extract important events (four, six, wicket)
* Reduce overall video duration
* Add labels for clarity
* Produce a professional highlight video

## Future Improvements
* Automatic event detection using AI
* Audio-based excitement detection
* Live match integration
* Web-based user interface
